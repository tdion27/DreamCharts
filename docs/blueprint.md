# **App Name**: Chartify

## Core Features:

- Last.fm Integration: Connect to multiple Last.fm accounts via the Last.fm API.
- Data Aggregation: Aggregate listening data from connected accounts to generate combined charts.
- Chart Generation: Generate a top 40 chart based on the aggregated data for a specified time period, using generative AI to make recommendations to create improved song curation as a tool
- Chart Display: Display the generated chart in a visually appealing and shareable format.
- Social Sharing: Enable users to share their generated charts on social media platforms.
- Account Management: Allow users to manage their connected Last.fm accounts.
- Period Selection: Allows users to choose time periods to select data from for chart generation.

## Style Guidelines:

- Primary color: A vibrant purple (#A020F0), drawing inspiration from music and creativity, evoking a modern and energetic feel.
- Background color: Light gray (#EEEEEE), offering a clean backdrop that allows the vibrant purple to pop, ensuring readability and focus on the content.
- Accent color: A contrasting blue (#3498DB), providing highlights and call-to-action prompts that stand out against the purple and gray.
- Headline font: 'Poppins', a geometric sans-serif providing a fashionable, contemporary, precise look.
- Body font: 'PT Sans', a humanist sans-serif providing readability.
- Use sleek and modern icons that represent music notes, charts, and social sharing actions.
- Maintain a clean and organized layout that's easy to navigate, with clear sections for account management, chart generation, and social sharing.
- Incorporate subtle animations when generating charts, creating a sense of excitement and progress.
